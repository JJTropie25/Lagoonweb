# lagoon-web

Landing page for **Lagoon** — *your city, shared.* Lagoon lets people find and book luggage storage, showers, workspaces and rest areas at partner venues in the city.

Part of the [Jungle](https://github.com/JJTropie25/jungle) project, alongside [lagoon-app](https://github.com/JJTropie25/lagoon-app).

## Contents
- `index.html` — main landing page
- `host-info.html` — information page for venue hosts/partners
- `images/` — site assets
